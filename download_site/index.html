How to install

  1. Tap Download for Android and open the file when it finishes.
  2. If asked, allow your browser to install unknown apps (Settings > Apps > Special access > Install unknown apps).
  3. Tap Install, then open the app.

If Google Play Protect shows a warning, choose “Install anyway”. The app is distributed directly, not through the Play Store.

Updating? Download and install over the existing app; your data is kept.

Android 7.0 or newer
