# ADR 009: Typed routes via go_router_builder

## Status
Accepted

## Decision
Feature navigation uses `GoRouteData` subclasses in `lib/app/router/routes/typed_routes.dart` generated by `go_router_builder`. Features call `.push(context)` / `.go(context)` on route types, not string paths.

## Consequences
- Compile-time route locations and query params.
- `dart run build_runner build` required when routes change.
